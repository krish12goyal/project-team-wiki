System Architecture & Core Logic

Built to solve complex synchronisation and concurrency problems at the backend level.

01
Tri-Layer Storage Architecture

Data writes are orchestrated across MongoDB → File System → Git Repository in strict order, ensuring consistency at every layer.

02
Promise-Based Git Mutex Queue

Forces async Git transactions into sequential promise chains. Prevents fatal .git/index.lock corruption under concurrent writes.

03
Synchronous Permission Funnel

Strict authorisation using hierarchical integer math to evaluate role levels and deflect malicious API manipulation at every endpoint.
